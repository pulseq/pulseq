Pulseq on GE — Online Tutorial Course — December 7–18, 2026

October 2026

December 7–18, 2026 | Mondays, Wednesdays, Fridays | 10 AM–12 PM ET

We are organizing a free online tutorial course on developing, simulating, debugging, and running Pulseq sequences on GE MRI scanners.

The course will feature live lectures, software demonstrations, a live scanner demonstration, and optional hands-on exercises. It is intended for MR scientists interested in developing and running research pulse sequences on GE scanners.

Tentative Program

Week 1 (December 7, 9, 11)

Mon, Dec 7: Introduction and Pulseq fundamentals; Writing GE-compatible Pulseq sequences

Wed, Dec 9: GE system architecture; pge2 interpreter architecture and workflow

Fri, Dec 11: Running Pulseq on GE — live scanner demonstration (2 hours)

Week 2 (December 14, 16, 18)

Mon, Dec 14: Simulating and debugging Pulseq-on-GE (2-hour tutorial, including virtual machine environment)

Wed, Dec 16: Safety management; Raw data and reconstruction

Fri, Dec 18: pge3 architecture, demo and roadmap; Advanced applications and community discussion

Tentative speaker list

Jon-Fredrik Nielsen — University of Michigan

Matteo Cencini — IRCCS Stella Maris

Ty Cashen, Nate Roberts, Eric Printz, Florian Wiesinger — GE HealthCare

New features and performance improvements

April 2026

Please check out the current Pulseq-Matlab repository, it contains substantial performance improvements and some exciting new features. Amongst them, a substantial speed-up of the basic event library infrastructure and seq.testReport(), more consistent behavior of function that modify Pulseq objects (e.g. mr.align() or mr.scaleGrad()), allowing to detect programming errors and performance penalties. We now also introduce an initial version of the seq.autoLabel() function, which is able to add labels to a many of Cartesian sequences and thereby make them compatible with the integrated image reconstruction on the scanner.
